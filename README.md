# 竹知了 · 哇声大作战 Toy

这是一个独立的 B站 Toy 游戏项目，基于开源项目《竹知了》的核心玩法改编：按住画圈甩动竹蝉，听它“哇哇”叫。

## 游戏玩法

- 选择“经典 · 30秒”或“极速 · 12秒”模式。
- 手动按住画圈，甩出的整圈会计入本局哇数；连续甩动会累积连击奖励。
- 每天轮换一个“今日秘令”：目标可能是哇数、最高速度或连击数。
- 结束后生成称号与得分；在 Toy 客户端登录后会提交到对应榜位。
- “自动甩”只用于试听，不计入挑战。

## Toy 榜单

- 经典模式使用 Toy 榜位 1，极速模式使用榜位 2。
- 游戏内可以切换今日、本周、本月和总榜，并查看个人名次。
- 游客仍可完整游玩；公开榜单可直接读取，个人名次和成绩提交需要登录。
- 页面底部的“同玩”信息使用公开榜单中的真实榜首分数、上榜人数和个人名次，榜单暂不可用时才降级为本地提示。
- Toy SDK 不提供页面内实时在线人数或全局访问量读取接口；这类 PV/UV 数据仍以创作者后台统计为准。

## 分享玩法

- 结算后可以生成“哇声成绩卡”，支持手机系统分享、保存图片和复制挑战链接。
- 挑战链接会带上模式与目标分数；朋友打开后会直接看到“超过好友成绩”的提示。
- 分享卡包含哇数、得分、最高速度、连击和当前排名，让成绩可以被晒出来、接着玩起来。

## 本地预览

直接打开 `index.html` 即可；也可以在当前目录运行：

```bash
python3 -m http.server 8123
```

然后访问 `http://localhost:8123/`。
